# AI Chatbot

## About
A simple AI chatbot built using Python and Ollama.

## Features
- Accepts user messages
- Generates AI responses
- Runs locally using Ollama

## Technologies Used
- Python
- Ollama
- GitHub

## How to Run
1. Install Python and Ollama.
2. Download a compatible Ollama model.
3. Run the chatbot using:

bash
python mychatbot.py
